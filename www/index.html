Programmer's Guide to the Fineline Library

This documentation describes how to use the -lfineline library in your program. Each chapter covers a different feature. The features are largely independent of each other, which helps because each chapter can be tightly focused.

It is not user documentation. There are no instructions about which keystokes performs what action. See the README.md file for that.

Chapters

1. IntroductionThis begins with an example program, and then proceeds to give a broad overview of the library and its capabilities.
2. HistoryIn-memory history is trivial, but if you want history to persist between sessions then you need to add functions to save it to a file, and reload it later.
3. Display StylesHere we explain the callbacks used for outputting text to the terminal, and controlling the cursor position. The ANSI terminal interface is explained in detail.
4. Full-Screen (ncursesw)This builds on the previous chapter to show how the callbacks are used in full-screen programs, via the -lncursesw library.
5. Syntax ColoringYet another callback implements syntax coloring. Syntax coloring can be complicated because syntax is complicated, but *fineline*'s interface is simple. It is also responsible for determining whether an <Enter> keystroke should be inserted as part of a multi-line input, or indicate the end of the current input
6. Name CompletionThis explains how name completion is implemented, and how to write your own callback to support it.
7. HintingHinting is different from name completion. Name completion tries to find text that can be inserted into the input, while hinting offers context-sensitive advice such as the parameters of functions.
8. Chat and AIThis allows asynchronously-received text to be displayed above your input. It is intended for AI chat, but could work for any asynchronous updates. You can configure selected parts to be inserted into your input automatically.
9. Cut and PasteThe cut, copy, and paste commands normally just move text within the fineline library, but you can add callbacks to access your GUI's interprocess cut/paste.
10. File EditorThe fled editor edits files, using the same edit commands as the line input functions. You can easily implement similar functionality within your own program.
